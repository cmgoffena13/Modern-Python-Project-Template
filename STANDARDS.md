# Standards

## Git Standards

### Branch Naming

 - All lowercase

Prefixes:
 - feat
 - fix
    - hotfix
 - refactor
 - chore
 - release

Format: {prefix}/{name}

Example: `feat/paypal-sync`

### Commit Standards

 - All lowercase
 - Don't end with a period

Utilize branch prefixes. 

Format: "{prefix}({code-context}): {message}"

Example: `"chore(readme): update setup steps"`
